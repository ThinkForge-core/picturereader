# OCR environment — RapidOCR on ONNX Runtime.
#
# WHY NOT PADDLEOCR
# -----------------
# `paddlepaddle` publishes no manylinux*aarch64 wheel from 3.3.0 onwards (the
# last ARM release is 3.2.2), and its `paddlex` dependency tree has no ARM
# wheels at all. On x86_64 it installs, but it drags in ~700 MB and caps the
# interpreter at 3.13. RapidOCR runs the *same* PP-OCR detection and
# recognition models through ONNX Runtime, which ships manylinux_2_28_aarch64
# wheels for cp311..cp314 — so this single environment installs cleanly on
# both x86_64 and aarch64 with no compiler and no source build.
#
# Everything below resolves to a prebuilt wheel on linux x86_64 AND
# linux aarch64 (verified against the PyPI JSON API):
#   onnxruntime           manylinux_2_28_aarch64
#   opencv-python-headless cp37-abi3 manylinux2014_aarch64 / manylinux_2_28_aarch64
#   pyclipper             manylinux_2_24_aarch64
#   shapely               manylinux2014_aarch64
#   Pillow / numpy / PyYAML / six / omegaconf / tqdm / requests / colorlog
#
# The `rapidocr` package itself is installed with --no-deps in a second pass
# (see scripts/install.py) so that its `opencv_python` requirement does not
# pull the GUI build: `opencv-python-headless` provides the same `cv2` module
# without the libGL.so.1 dependency, which matters inside a proot rootfs.
